# math-classics — 公版数学经典趣味交互站

把**已进入公有领域**的中国古代数学经典（《九章算术》《孙子算经》《几何原本》徐光启译本等），做成
「**原文 → 白话拆解 → 可交互作图 → 小练习**」的中文学习站。

- 参考的是「数学乐」那种**看得见、摸得着**的讲法，但**不翻译、不搬运**它的任何内容。
- 内容全部基于公有领域底本自行改写、自绘 SVG，可安全发布。
- 纯静态站，零后端、零 Cookie 追踪；登录是可选入口（统一账户中心），不登录也能正常使用。

## 怎么打开

用 Trae 打开 **`math-classics.code-workspace`**（不是直接打开 `Coding` 根目录）。
只有把本项目当作工作区根，`.trae/` 里的规则和技能才会生效（Trae 不继承父目录规则）。

## 怎么跑

```bash
cd /Users/Admin/Knowledge/Coding/math-classics/web
npm install        # 第一次
python3 -m venv .venv && .venv/bin/pip install sympy pyyaml   # 第一次（审核闸用）
npm run dev        # 开发模式，改文件自动刷新
# 浏览器打开 http://localhost:4321
```

看构建后的成品：

```bash
npm run check:math  # 只跑 sympy 审核闸（复算所有 checks）
npm run build       # 台账校验 → 审核闸 → 生成 web/dist/
npm run preview     # 预览构建结果
```

交互原语实验台：<http://localhost:4321/lab/>（构建后为 `/lab/index.html`）。

## MVP 做什么（一句话）

**一个站、三条内容线**：

- **九章算术线**：九卷各取一题，共 9 个命题——方田（面积）、粟米（比例）、衰分（配分）、少广（开方）、商功（体积）、均输（追及）、盈不足（双假设）、方程（线性方程组）、勾股。
- **孙子算经线**：第 1 题鸡兔同笼（半足术）。
- **趣味数学线**：按「图解 + 小实验 + 练习」原创，不复制、不翻译；栏目页 `/fun/` 已可进，首批选题筹备中。

首页是门户：一个英雄区 + 三张栏目卡 + 读法 + 关于；点进栏目页再看本书题目。命题页仍是 `/propositions/<id>/`，每个命题一页，3 分钟能做完，手机也能用。
